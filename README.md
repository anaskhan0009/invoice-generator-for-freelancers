# Free Invoice Generator for Freelancers & Small Businesses

A free, single-page **online invoice generator** — create professional invoices in the browser, with automatic totals, tax and discounts, then print or save as PDF. No sign-up, no server, works offline.

**Live demo:** open `index.html` in any browser (or enable GitHub Pages on this repo).

## Features

- Business & client details, invoice number, dates
- Unlimited line items with quantity × rate auto-amounts
- Tax % and flat discount, live grand total
- Multi-currency: USD, PKR, EUR, GBP
- Print / Save-as-PDF with a clean print layout
- Fully client-side — your data never leaves the browser

## Tech

Plain HTML + CSS + JavaScript (zero dependencies).
